
# my-seuteok

학생이 학번, 이름, 비밀번호를 입력하면 본인의 세부능력 및 특기사항(세특)을 조회할 수 있는 웹페이지입니다.  
본 시스템은 GitHub Pages를 통해 누구나 접속 가능하며, **엑셀 파일(`db.xlsx`)을 그대로 업로드**하면 학생 정보가 갱신됩니다. (별도 변환 과정 불필요)

---

## 🔧 구성 파일

| 파일명         | 설명 |
|---------------|------|
| `index.html`  | 사용자 입력 폼과 결과 출력 HTML 페이지 |
| `script.js`   | 입력값 검증 및 엑셀 데이터 검색 로직 (SheetJS로 브라우저에서 직접 파싱) |
| `style.css`   | 반응형 모바일/데스크탑 대응 디자인 |
| `db.xlsx`     | 학생 정보 DB (엑셀 파일 그대로 사용) |

---

## 🔄 학기별 데이터 갱신 방법

1. `db.xlsx`에 **새 학기 행들을 기존 행 아래에 추가**합니다. (열 구조는 아래 참고)
   - 행을 추가하면 학생이 지난 학기 기록까지 모두 (최신순으로) 볼 수 있습니다.
   - 지난 학기 기록을 보여주고 싶지 않으면 해당 행들을 삭제하면 됩니다.
2. GitHub 저장소 페이지에서 **`Add file → Upload files`** 를 클릭하고 `db.xlsx`를 드래그해서 업로드합니다. (같은 이름이면 자동으로 덮어쓰기됩니다)
3. **`Commit changes`** 를 누르면 끝! 몇 분 안에 사이트에 반영됩니다. (GitHub Pages 캐시로 최대 10분 정도 걸릴 수 있음)

> 파이썬 변환, JSON 작업 모두 필요 없습니다. 엑셀 파일 하나만 교체하면 됩니다.

## 📁 db.xlsx 기본 구조

`db.xlsx` 파일의 **첫 번째 시트, 첫 번째 행**에 다음 열 제목이 있어야 합니다:

| 학년도 | 학기 | 과목     | 학번   | 이름   | 세특                          | 비밀번호 |
|--------|------|----------|--------|--------|-------------------------------|-----------|
| 2025  | 2    | 물리학Ⅰ | 20101 | 홍길동 | 속력과 가속도의 차이를 분석함   | 1234      |
| 2026  | 1    | 물리학Ⅱ | 20101 | 홍길동 | 전자기 유도 실험을 설계함       | 1234      |

**한 행 = 한 학생의 한 과목 세특**입니다. 같은 학생이 과목이나 학기마다 한 행씩 차지하며, 조회하면 그 학생의 모든 행이 학기별로 묶여 최신순으로 표시됩니다.

### 🔹 열 설명

- `학년도` : 예) 2025
- `학기` : 1 또는 2
- `과목` : 과목명 (예: 물리학Ⅰ)
- `학번` : 학생 식별 번호
- `이름` : 학생 이름
- `세특` : 교과 세부능력 및 특기사항 내용
- `비밀번호` : 4자리 숫자 — **같은 학생은 모든 행에 같은 비밀번호**를 쓰는 것을 권장합니다 (학년도가 바뀌어도 유지하면 학생이 외우기 편합니다)

> 열 제목은 반드시 위 예시와 정확히 일치해야 조회 시스템이 정상 작동합니다.

---

## 🔐 비밀번호(4자리 숫자) 생성 방법

비밀번호 열에 다음 함수를 입력하면 각 학생마다 랜덤한 4자리 숫자가 생성됩니다:

```excel
=RANDBETWEEN(1000, 9999)
```

> **주의:** 이 함수는 시트가 열릴 때마다 값이 바뀔 수 있으므로,  
> 생성 후 전체 복사 → "값 붙여넣기"로 **고정**하세요.
